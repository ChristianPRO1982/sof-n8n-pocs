Les pages de Knowledge Manager

Rôle de chaque page dans le parcours cible ; les pastilles indiquent son état de développement.

  • 00a — Templates : déposer, remplacer et supprimer les modèles de documents dans un espace distinct des sources.
  • 00b — Import des fichiers historiques : déposer les anciens documents à préparer et à découper en fichiers basés sur les templates actuels.
  • 00c — Fichiers historiques traités : retrouver les sources historiques archivées après préparation réussie et transfert des documents produits vers le parcours standard.
  • 01a — Import des fichiers sources : déposer des fichiers de tous types, gérer les remplacements autorisés et supprimer les fichiers déposés.
  • 01b — Fichiers traités : retrouver les sources archivées après leur prise en charge initiale et l’enregistrement des résultats, avant validation métier.
  • 02 — Contrôles de format : vérifier sans LLM les styles, sections obligatoires, tableaux et acronymes du Word selon les règles du template.
  • 03 — Deltas : comparer le document à une référence avec une extraction JSON par LLM pour détecter et expliquer les écarts.
  • 04 — Rapports : consolider les contrôles et les écarts pour orienter le document vers une correction, une justification ou la suite du parcours.
  • 05 — Métadonnées : proposer les métadonnées par règles et LLM, puis vérifier leur conformité au JSON Schema avant revue métier.
  • 06 — Validation humaine : approuver ou refuser la version du document et ses métadonnées, avec retour en brouillon en cas de refus.
  • 07 — Connaissances : publier le Word approuvé avec ses métadonnées et archiver les versions précédentes.
  • 08 — Export Markdown : convertir le Word publié sans LLM en préservant les titres, listes et tableaux, puis contrôler la structure produite.
  • 09 — Base AI Ready : publier le couple de fichiers Markdown et JSON de métadonnées portant le même identifiant et correspondant à la version approuvée.
  • 10 — Journal de suivi : retracer les traitements, résultats, erreurs et décisions humaines tout au long du parcours documentaire.
